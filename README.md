# cavinum-license-status

Публичный реестр отзыва/понижения лицензий **Cavinum Pro** — единственное назначение
[`status.json`](./status.json) в этом репозитории: клиент Cavinum на плановой проверке лицензии
сверяет свой текущий локальный ключ с записью здесь и тихо принимает более новую, если она
отличается (в частности — если доступ был отозван).

Записи хранятся по SHA-256-хэшу email, не по самому адресу — по хэшу нельзя восстановить список
получателей. Здесь появляются только те, кому реально выдавался Pro-доступ; обычные пользователи
бесплатной версии в этом файле не фигурируют вообще.

Файл публикуется автоматически GitHub Actions-воркфлоу приватного репозитория
[`cavinum-lic`](https://github.com/andiboost/cavinum-lic) при каждой выдаче, пересылке, апгрейде
или отзыве лицензии — вручную не редактируется.
